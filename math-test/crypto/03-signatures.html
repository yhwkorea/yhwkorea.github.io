현대 암호학 · 전자서명

RSA부터 SLH-DSA까지 무엇이 다른가

모든 방식은 KeyGen·Sign·Verify를 제공하지만 기반 문제, 크기, 난수 요구, 구현 위험이 다릅니다.

1. 공통 인터페이스와 보안 질문

KeyGen() → (public_key, secret_key)
Sign(secret_key, message) → signature
Verify(public_key, message, signature) → true / false

전자서명은 내용을 숨기지 않습니다. 공격자가 이미 본 메시지들의 서명을 선택해서 받아본 뒤에도 새로운 유효한 메시지·서명 쌍을 만들기 어려워야 합니다.

2. RSA-PSS

RSA-PSS는 큰 정수의 인수분해 난이도와 RSA 문제에 기반한 고전 서명입니다. 메시지 자체에 ‘비밀키로 RSA 암호화’를 하는 설명은 부정확합니다. 해시, salt, mask generation을 포함한 PSS 인코딩 전체가 보안 설계의 일부입니다.

충분히 큰 양자컴퓨터의 Shor 알고리즘 대상이므로 후양자 서명이 아닙니다. 기존 호환성과 검증 생태계 때문에 여전히 중요합니다.

3. ECDSA와 EdDSA

ECDSA는 타원곡선 이산로그 문제에 기반합니다. 서명마다 쓰는 nonce가 반복되거나 예측되면 두 서명에서 비밀키가 계산될 수 있습니다. EdDSA는 Edwards 곡선과 결정론적 nonce 파생을 포함한 별도 설계이며 ‘ECDSA의 인코딩만 바꾼 것’이 아닙니다.

둘 다 Shor 알고리즘의 영향을 받는 고전 서명입니다.

4. ML-DSA

ML-DSA는 FIPS 204로 완성된 모듈 격자 기반 후양자 서명입니다. 서명자는 짧은 비밀과 무작위·결정론적으로 파생한 마스킹 값을 사용해 공개 선형 관계에 대한 짧은 응답을 만듭니다.

일부 후보 응답은 비밀 정보를 통계적으로 새게 할 수 있어 조건을 만족하지 않으면 다시 표본합니다. 이 rejection sampling과 정확한 인코딩을 생략하면 안 됩니다. 파라미터 세트 ML-DSA-44·65·87은 크기와 보안 강도의 절충입니다.

5. SLH-DSA

SLH-DSA는 FIPS 205의 stateless 해시 기반 서명입니다. one-time signature들을 Merkle 계층으로 묶고 FORS와 WOTS+ 구조를 사용합니다.

격자와 다른 보안 기반을 제공하지만 서명이 큽니다. stateless는 ‘아무 상태도 없다’가 아니라 같은 one-time leaf를 위험하게 재사용하지 않도록 주소와 난수를 메시지에서 안전하게 파생하는 구조를 뜻합니다.

6. FN-DSA

FN-DSA는 FALCON에서 표준화되는 NTRU 격자 기반 서명이며 FIPS 206은 개발 중입니다. 짧은 서명과 빠른 검증이 장점이지만 Gaussian sampling과 부동소수점·정수 구현의 정확성, side channel 방어가 까다롭습니다.

‘표준화 대상으로 선택’과 ‘최종 FIPS 발행’을 구분해야 합니다.

7. LMS와 XMSS

SP 800-208의 LMS와 XMSS는 상태를 유지하는 해시 기반 서명입니다. 서명할 때마다 사용한 leaf를 기록해야 하며 상태가 롤백되어 동일 one-time key를 재사용하면 안전성이 깨집니다.

펌웨어 서명처럼 중앙에서 상태를 엄격히 관리할 수 있는 특수 환경에는 유용하지만 일반 사용자가 여러 복제 장치에서 서명하는 기본 도구로 다루면 위험합니다.

8. 무엇을 비교해야 하나
